# 界面样式

界面继续使用 Material 3 和现有铜色主题。通用样式由 `lib/ui/design.dart`
和 `bitreeTheme` 维护，页面不再为同类控件另设圆角、选中颜色或默认字号。

## 形状与间距

| 类型 | 规则 |
| --- | --- |
| 按钮、表单、下拉触发器、菜单、分段选择、标签、导航选中背景 | 10px 圆角 |
| 对话框、底部弹层 | 20px 圆角；底部弹层只圆顶部 |
| 课表紧凑块、小标记、提示标签 | 6px 圆角 |
| 完成状态、地图定位点、时钟表盘、图表 | 保留表达其含义的形状 |

普通操作的最小触摸目标为 48px。按钮使用同一字号、字重和内边距；
更新对话框等需要并排容纳多个操作的场合，可以缩小内容尺寸。
顶栏下拉使用 `AppMenuTrigger`，表单下拉使用 `AppDropdownField`。
表单菜单默认不窄于输入框，长选项按内容加宽，并受屏幕边界约束。

弹层标题使用 `SheetHeader`，标题、正文和底部操作对齐到左右 24px。
底部弹层宽度由主题统一限制为最多 560px，小屏随可用空间收缩。
条目自带内边距时按最终内容边缘对齐，不重复叠加。
`AppPage` 只给顶栏保留手机 16px、桌面 24px 边距，主体不统一加左右留白。
课表铺满可用宽度；列表优先使用条目自身边距，表单和浮动提醒各保留一层
必要边距，避免重复叠加。

## 颜色与动效

主要操作使用主题主色；选中项使用主题选中底色和配套前景色。
次要信息使用 `onSurfaceVariant`，错误和逾期使用 `error`。
浅色与深色均从 `ColorScheme` 取色。

菜单统一使用 `AppMenuAnchor`，展开 300ms、收起 200ms；箭头使用同一个
`AppMenuArrow`。开启减少动画时直接切换，不增加独立的页面动画参数。
菜单按触发器上下的实际可用空间限制高度，放得下的内容完整显示，空间不足时滚动。

首页横滑越过半页时更新周数，拖回时同步恢复。浏览当前学期的其他周时，
周次右侧显示“回到本周”；空间不足时使用带提示的图标。当前学期按本地校历
和设置的周次范围判断，范围重叠时以开学日期较新的学期为准。

新增控件优先复用原生组件的主题；只有确实共用布局或交互时才提取组件。

## 课程与日程

课程按良乡校区的楼栋片区配色：综教蓝色、文萃绿色、南部理科教学与实验区黄色。
其他楼栋按校方地图上的位置归组，相邻楼栋在同一色系内微调。楼栋别名、片区和
浅深色表统一由 `tool/building_palette.py` 生成，Flutter 与 Android 小组件共用。
片区颜色表示位置关系，不表示步行距离或路线。

深色课表将楼栋底色向同色系强调色提亮，课程块、地点文字与进度填充均使用
不透明色。当天列使用中性表面色，避免铜色罩染；日程时间轴沿用原有配色和渐变。

在设置的“关于 BITree”弹窗中连续点击图标 5 次（相邻点击不超过 2 秒），
可解锁本次运行的开发者模式，并显示“更多设置”。开发者模式不持久化；
深色模式调色板选项会独立保存，重启后仍应用已选配色。
默认选项保留原有楼栋配色；Mocha、Macchiato、Frappé 使用
[Catppuccin](https://github.com/catppuccin/palette) 的 Base、Text 和片区强调色，
依次以蓝、绿、黄、紫、桃色对应北部教学、文萃、南部理科、东部设施和南部工科，
未知地点使用中性色。底色向强调色混合 24%，已上时段再混合 16%，次要文字
从底色向正文色混合 80%。这些选项作用于应用和 Android 小组件中的深色课程块。
Android 12 及以上，小组件背景、标题、次要文字和主题强调色始终读取系统动态色，
不受课程调色板或开关影响。开发者模式中的“小组件使用系统调色板”默认关闭，
关闭时课程沿用自选调色板；开启时仅小组件课程改用系统色，应用内课程保持原样。
系统课程色按片区使用三组强调色，并通过明度区分同组片区；未知地点使用中性色。
Android 12 以下保留原有背景和课程配色，深色背景可回退到所选 Catppuccin 的 Base。
应用全局背景、当天列和非课程日程的配色保持原样。
切换调色板或开关会同步已选课程色值和开关状态，并立即刷新小组件；应用启动时也会同步。
Android 端保存这些设置，在应用关闭后刷新时读取当前系统颜色。
调色板选择和开关都持久化，开发者模式的解锁状态不持久化。

当天课程保留 1.5px 同色系轮廓；正在上的课程用本楼栋底色与强调色
混合填充已上完的部分。轮廓不占文字空间。时间线独立绘制在课表上层，贯穿七列：
当天保持 2px 原色，两端略收进卡片边缘，避免在侧边间隙露出短点。
其他日期为 1px 淡色实线，直接位于卡片上方。当天课程的圆角作为蒙版，线在卡片内按
同色系强调色叠加：浅色模式加深、深色模式提亮，与已上时段的填充保持清楚对比，
保留文字明暗；圆角外自然露出原色。
进度填充与时间线共享同一中心坐标；卡片的 2px 内缩只限制填充范围。
时间线始终按节次位置移动，课间停在节次边界，不在课程开始或结束时切换绘制方式。
课程结束后恢复普通底色；课表时段外，独立时间线仍停在下一次早课起点。

点击课程打开课程 drawer，展示下一门课和换楼关系；点击下一门课在同一 drawer
内查看。点击日期打开当日日程 drawer，复用日程列表的完成与滑动操作，已完成项折叠。
课程不计入日程数量，也不跳转到日程页面。
