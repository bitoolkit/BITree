# 文萃地图

工具、文萃课程详情和空教室详情共用离线交互地图。`places.json` 保存原图中
可辨认房间、入口、楼梯、电梯和卫生间的文字及轮廓。点击和搜索使用同一索引；
搜索命中时放大并高亮房间，未收录的号码只显示对应楼栋范围。
不从楼栋色块、直线距离或房间邻近关系推导可通行路径。

课程详情将位置预览与地图入口合并；预览显示完整楼层缩略图，以圆点标记教室，
保留教室在各楼栋之间的方位；未收录的教室只高亮楼栋范围。点击预览进入地图时，
先显示对应楼层的整层总览，并保留课程名和教室高亮；点击“回到教室”可放大定位。
整层视图可点楼栋放大，楼层按钮支持逐层切换和直接选层。“我的文萃课程”
直接使用当前本地课表，无需重新导入。M、B、G、H 的楼栋按钮根据本层所属房间和设施
范围放在 L 形楼体的对应折角，并向内收；按钮位置不使用为取景纳入的周边设施。
楼梯、电梯和卫生间按需显示，设施标记使用 44 像素点击区域；
查看设施或切换楼层后仍可回到目标教室。
地图点选只更改选中对象，不自动拉动视野；搜索、楼栋选择和定位按钮才移动镜头。

从[公开存档](https://github.com/Zebedee2021/BIT-Nav-2026/tree/main/wencui)取得。
原图链接记录在该存档的 `data/archive/floorplans/floorplan_urls.json`。
未使用该项目的代码、示范房间数据或导航图。

**原始楼层图上东、左北**。应用保持原图比例；房间轮廓、点击区域和缩放目标
全部使用各层原图的归一化坐标，不跨楼层套用一组近似的楼栋矩形。
高层图保留了没有房间的楼栋背景色，因此只允许定位到图上标出房间的楼层：
A 3–7 层；B/G/H/M 1–2 层；D/F/I/K 1–7 层；C/E/J/L 1–10 层。

更新底图时应同时核对 `WencuiWing` 的楼层范围及 `places.json` 的坐标。
7层 L 区有一处 J-701 标注，与 J 栋教室号冲突；该处未建立教室号定位，避免猜测门牌。
